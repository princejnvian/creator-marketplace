# YOUTENT

YOUTENT is a creator marketplace MVP built with Next.js, Supabase and Razorpay.

Client signs in → finds a freelancer → views portfolio → messages or hires → freelancer accepts → client pays the project amount + ₹50 YOUTENT platform fee → Razorpay payment is verified → project unlocks → freelancer delivers → client approves → project payment is released to the freelancer wallet.

## Setup

1. Run `npm install`.
2. Add Supabase and Razorpay environment variables.
3. Run `MVP-SUPABASE-MIGRATION.sql` once in Supabase SQL Editor.
4. Run `npm run dev` or `npm run build`.
